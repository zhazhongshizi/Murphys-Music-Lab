# Dependency comparison baseline

These two unmodified dependency manifests come from public commit
`07f53de64f1150508f1ee270dd3d03311b9c2437` (version 1.3.3).
The notice generator uses them to identify the added Rust dependencies and to
compare the frontend runtime closure. Keeping the manifests here makes notice
generation work from a source archive without private Git history.

They are project source covered by the repository's GPL-3.0-or-later license.
